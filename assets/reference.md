# 实习经历

## 网易游戏 - 内容制作中心 | AI 产品实习生

**2026.03 - 2026.08**

**项目背景：**参与网易游戏 AI 应用平台建设，负责游戏营销素材自动化模块的产品方案，面向运营与设计团队解决通用 AI 难适配内容模型、固定素材规格及品牌规范的问题。

### 游戏营销素材自动化生产（召回老玩家、拉新与付费转化）

- **交付效率数量级提升：**将人工单张制作改为自动批量生成，12–15 分钟最多产出 **128 张**投放素材，已应用于梦幻西游、永劫无间等 **20+ 款游戏**，覆盖微信、应用商店等 **64 个渠道**。
- **降低非专业用户使用门槛：**将复杂参数收敛为默认配置，并通过 A/B 双版及失败重生成兜底。经业务验收可直接投放的素材首次通过率约 **90%**，兜底后可用率达 **95%**。
- **投放策略资产化：**沉淀 **614 条**场景数据集，涵盖六类投放策略分类、按渠道自动匹配，并独立设计“投流数据回流 → 清洗 → AI 定期生成提示词入库”的迭代机制。
- **多模型分级调度：**依据任务质量要求与模型能力边界进行模型路由。按模型调用单价及实际任务量测算，在维持良品率的前提下，单张调用成本降低约 **70%**。

### 跨模块内容资产库

- **一次沉淀，多场景复用：**统一归集角色库、场景库等素材管理，构建站点多模块共用的资产库，避免重复造轮子，一次生产即全平台复用。支持生图、模板替换及投流视频的直接调用。按制作成本与调用记录统计，单要素生产效率提高约 **65%**，复用率提升至 **70%+**。

### 多模态资源生产 Agent

- **将跨工具操作压缩为单次输入：**通过 Agent 与平台生产管线对接，自主完成任务拆解、批量生成、状态追踪及终稿获取，形成端到端生产流程。
- **支持 AI 统一编排平台能力：**定义可被 Agent 调用的能力清单、输入输出、状态反馈与异常处理协议，使平台工具可统一调度，并为后续接入其他生产工具预留标准化入口。
